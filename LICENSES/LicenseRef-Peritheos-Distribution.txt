Peritheos distribution licensing scope

LicenseRef-Peritheos-Distribution identifies the component-specific terms of
the Python distribution. It is a summary reference, not a new license or a
grant over third-party material.

Peritheos implementation code and contributor-authored documentation use the
MIT (Expat) license in LICENSE. References to scientific articles in code do
not change that code license. Explicit additional grants remain available.

Scientific data and retained third-party artifacts have separate terms.
The runtime distribution omits experimental observation values. The optional
peritheos-datasets distribution contains only its explicit, source-scoped
selection and retains the corresponding dataset notices. Repository research
evidence is not automatically part of either distribution.
Consult peritheos/data/LICENSING.md, the included dataset-specific notices,
and each resource's source/rights metadata. Some source datasets are CC BY
4.0 or CC0; other source terms are unspecified or restricted. A contributor
CC0 dedication covers only the contributor-held rights stated in its notice.
It does not grant rights held by the authors or publishers of source material.

Rust dependencies and standard-library components retain their upstream
licenses and notices in peritheos/data/third_party/rust/. The manifest records
source versions, hashes, target roles and the audited publication compiler.
These are separate from the MIT license of Peritheos implementation code.

MIT, CC BY 4.0, CC0 and Rust third-party notices are included. Their presence
does not apply any of these licenses to files outside their stated scope.
Unknown source terms remain unknown; this reference does not establish that
every bundled resource meets a downstream distributor's licensing policy.
