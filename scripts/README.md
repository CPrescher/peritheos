# Research and maintenance scripts

Peritheos contributor-written scripts in this directory use the repository's
[MIT (Expat) code license](../LICENSE), unless an explicit file-specific notice
says otherwise. Explicit additional contributor grants remain available.
Scientific citations and the licenses of input datasets do not change the
license of these scripts. Preserve separate source terms when redistributing
their inputs or outputs containing source-derived content.

The [installed licensing guide](../peritheos/data/LICENSING.md) explains the
data notices, contributor-only CC0 dedications and unspecified source terms.
Original third-party author scripts retained under `docs/data/` keep their
own source licenses; Katsura's MATLAB files, for example, are CC BY 4.0.

These scripts are repository/source-distribution research and maintenance
tools. They are not an installed public Python API. Follow each script's
documented inputs and preserve original evidence separately from diagnostics.
