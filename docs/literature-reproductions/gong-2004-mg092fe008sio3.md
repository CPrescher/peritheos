# Gong et al. (2004): shock-derived (Mg0.92Fe0.08)SiO3 perovskite EOS

Primary source: Z. Gong, Y. Fei, F. Dai, L. Zhang, and F. Jing, “Equation of state and phase stability of mantle perovskite up to 140 GPa shock pressure and its geophysical implications,” *Geophysical Research Letters* **31**, L04614 (2004), DOI [10.1029/2003GL019132](https://doi.org/10.1029/2003GL019132).

## Audit result

- **ACCEPT — LitCurate source row 447.** The publisher full text reports 13 shock states from 47.75 to 140.64 GPa, the reduced third-order Eulerian finite-strain coefficients K0S = 260.1(9) GPa and K0S' = 4.18(4), and the adopted perovskite reference density 4.19 g cm-3. The executable BM3 record preserves those adiabatic coefficients. Its conventional Pbnm Z=4 reference volume is calculated exactly from the reported density and the nominal (Mg0.92Fe0.08)SiO3 molar mass; no unreported crystallographic volume is invented.
- **REJECT — LitCurate source row 461, DOI 10.1063/1.1780510.** The AIP conference proceeding reports the same Damaping sample, same 13 shock experiments, same velocity relation, and the same finite-strain reduction, rounded as 260.09 GPa and 4.17. It is not an independent EOS and would be a duplicate pseudo-record.

The source calls K0S adiabatic. Peritheos currently distinguishes equilibrium finite-strain models from thermal and Hugoniot models using the historical `isothermal` equation-kind token; the record label, parameter provenance, and validation text explicitly retain the adiabatic meaning rather than silently relabeling K0S as K0T.

## Reproduction

`scripts/reproduce_gong_2004_mg092fe008sio3.py` reads the complete publisher Table 1 transcription, checks the published `us = 3.76 + 1.48 up` relation against all 13 observations, independently converts 4.19 g cm-3 to the stored Z=4 reference volume, and evaluates the published BM3 coefficients at fixed compression checkpoints.

Run:

```bash
uv run python scripts/reproduce_gong_2004_mg092fe008sio3.py
uv run pytest -q tests/test_gong_2004_mg092fe008sio3.py
```
