# Farla et al. (2025) rubidium halide data attribution

Primary article: R. Farla, A. Néri, M. Pöppelbaum and K. Glazyrin,
*Thermal equations of state of B2-structured rubidium halides RbCl, RbBr,
and RbI*, Journal of Applied Physics 137, 115901 (2025),
<https://doi.org/10.1063/5.0248905>.

Numerical tables S1-S7 are from the official AIP supplement, version 1:
Farla, Robert; Néri, Adrien; Pöppelbaum, Melanie; Glazyrin, Konstantin
(2025), *Supplemental Materials (Clean)*, AIP Publishing,
<https://doi.org/10.60893/figshare.jap.28515917.v1>.
Its public API metadata identifies **CC BY 4.0**:
<https://creativecommons.org/licenses/by/4.0/>.
Source file: `JAP24-AR-06680R_SupplMat_round2.docx`, Figshare file 52698776.

The CSV files expand printed parenthetical errors, preserve source tokens and
missing cells, attach compound/run/table identifiers, and duplicate reported
CsCl pressure into the common pressure column for the preferred case-1 EOS.
The raw numerical table cells are also retained as JSON. The source tables are
not replaced by calculated values or smoothed/refitted observations. The S5-S7
tables contain calculations and are explicitly separate from observations.
